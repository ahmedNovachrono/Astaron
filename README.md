# AI Learning Platform Backend (STILL UNDER DEVELOPMENT)

A backend system for an AI-powered learning platform that helps students transform complex educational content into simplified learning materials.

## Overview

This project was built to improve the learning experience by leveraging AI to automatically process educational content and generate study resources. The platform aims to help students understand difficult topics faster and retain information more effectively.

## Key Features

### AI-Powered Content Simplification
Converts complex educational content into simplified and easy-to-understand explanations.

### Flashcard Generation
Automatically creates study flashcards from learning materials to support active recall learning.

### Authentication & Authorization
Secure user registration, login, and protected routes using JWT authentication.

### Subscription Management
Supports subscription-based access and user plan management.

### Automated Reminder Workflows
Schedules subscription renewal reminders using background workflow automation.

### API Protection
Implements bot detection, rate limiting, and request protection mechanisms.
